# 黄昏の聖域 — The Twilight Sanctuary

擬似3Dのダンジョン探索と、グリッド式の戦術戦闘を組み合わせたブラウザRPG。
外部ライブラリを使わない単一HTMLで、`index.html` を開くだけで動きます。

**▶ プレイする: https://ozwaldboateng-lab.github.io/twilight-sanctuary/**

## 内容

- 擬似3D迷宮探索（地下6階層・階段・ワープ・祭壇・ミニマップ）
- グリッド式戦術戦闘（移動／攻撃／魔法／範囲魔法／反撃／クリティカル／種族特効）
- 3職業（賢者・戦士・僧侶）とクラスチェンジ（大賢者・剣聖・聖女）
- 酒場で雇える同行者4人（狩人・盗賊・忍者・侍）と固有スキル
- 装備・消費アイテム・ドロップ（common 〜 relic）
- 町（宿屋・教会・武器屋・酒場）とセーブ／ロード
- 中ボス5体・最終ボス・周回による強化

## 操作

| | PC | スマートフォン |
|---|---|---|
| 探索 | ↑↓←→ または WASD | 画面下の方向ボタン |
| 戦闘 | ↑↓←→ でカーソル移動／Enter で決定／Tab で味方切替／Esc で選択解除／q・e・r で待機・行動終了・魔法 | マスをタップ |

画面の縦横比に応じて、縦1カラム・横2カラム・PC向けワイドの3種類のレイアウトに自動で切り替わります。

## 技術メモ

- 依存ライブラリなし。描画は Canvas 2D、効果音は Web Audio API で合成
- 画像はすべて data URI として埋め込み済み（フォントのみ Google Fonts から取得、未取得時は明朝体にフォールバック）
- セーブデータはブラウザの localStorage に保存されます
